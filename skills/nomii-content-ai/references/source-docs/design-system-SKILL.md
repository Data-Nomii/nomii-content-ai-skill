Read the `readme.md` file within this skill, and explore the other available files (tokens/,
components/, guidelines/, ui_kits/carousel/, assets/).

If creating visual artifacts (carousels, slides, mocks, throwaway prototypes, etc), copy assets
out and create static HTML files for the user to view. If working on production code, copy assets
and read the rules here to become an expert in designing with this brand.

Essentials to never break:
- Colors: celeste `#77BFD0`, azul `#104574`, dark text `#3C3C3B`, soft bg `#F8F8F8` (never pure white).
- Type: **Rubik only** — Light (body), Medium (titles/keywords), Medium Italic (emphasis/pills).
  **Bold is prohibited.** Sentence case. No emoji.
- Carousel canvas: 1080×1440 (3:4); 85px top/bottom + 63px side safe area; logo top-right 200px;
  centered isotipo circle on the CTA lámina.
- Voice: Spanish, empathetic then strategic, second person "tú".
- Never redraw or recolor the logo/isotipo — use only the provided asset files.

If the user invokes this skill without other guidance, ask what they want to build or design, ask
a few clarifying questions (topic, number of laminas, goal/CTA), and act as an expert NOMII
designer who outputs HTML artifacts or production code depending on the need.
